# SnipToss

A memo helper for macOS and Windows.

## Download

Get the latest version from [Releases →](../../releases/latest)

- macOS Apple Silicon: `sniptoss-*-arm64.dmg`
- macOS Intel: `sniptoss-*-x64.dmg`
- Windows: `SnipToss-*-win.zip` (unzip and run `SnipToss.exe`)

## First launch

**macOS**: System Settings → Privacy & Security → "Open Anyway"

**Windows**: Click "More info" → "Run anyway" on the SmartScreen prompt
